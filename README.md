# A/B 测试与因果推断实验室 · AB Testing Lab

基于**十万次级可复现模拟**的 A/B 实验方法学完整报告：实验设计 → AA 检验 → 功效验证 → 偷看问题 → 多重检验 → CUPED 方差缩减 → 辛普森悖论 → 收益估算，九个环节全部用模拟定量验证。

**在线报告**：<https://cloud1-d4gsgj705497df85d-1501559031.tcloudbaseapp.com/ab-lab/>

## 核心结论（全部可复现，随机种子固定）

| 环节 | 模拟结果 | 理论值 |
|---|---|---|
| AA 检验假阳性率 | **4.98%** | α = 5% |
| 功效模拟（10 万次） | **80.09%** | 目标 80% |
| 每天偷看结果的假阳性 | **28.1%**（膨胀 5.6 倍） | 结束看 1 次 4.99% |
| 5 指标不校正的族错误率 | **22.6%** | 1−0.95⁵ = 22.6% |
| Bonferroni 校正后 | **4.9%** | 5% |
| CUPED 同样本量功效 | **50.7% → 71.4%** | 方差缩减 ρ²=36% |

实验场景：基线转化率 5%、检测 10% 相对提升（MDE 0.5pp）、每组 31,231 样本。

## 这个项目展示什么

1. **实验设计能力**：样本量公式不是背的——MDE 从 2pp 缩到 0.5pp，样本量 ×16 的平方级关系直接画出来。
2. **平台健康意识**：AA 检验是上实验前的标准动作，p 值分布均匀是分流无偏的证据。
3. **对常见错误的定量直觉**：偷看使假阳性膨胀 5.6 倍、5 个指标的看板有 22.6% 概率"都在涨"——每个面试常客都被模拟钉在了数字上。
4. **CUPED 实现与坑**：中心化必须用总体期望（样本均值会吸收处理效应）；两组必须独立采样（共享噪声矩阵会把实验模拟成配对设计）——这两个错误在开发中真实踩过，代码注释里留着记录。
5. **统计到业务的翻译**：收益估算永远带置信区间，点估计只是故事。
